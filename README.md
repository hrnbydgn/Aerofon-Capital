# Drone Ground Control Station (GCS)

Web tabanlı, mobil uyumlu drone kontrol istasyonu uygulaması.

## Özellikler

- ✈️ Gerçek zamanlı telemetri gösterimi
- 🗺️ Canlı harita görünümü
- 📹 Video stream desteği
- 🎯 Görev planlama
- 📊 Attitude ve compass göstergeleri
- 🔋 Batarya ve GPS durumu
- 📱 Sadece yatay ekran desteği
- 🎨 Modern ve kullanıcı dostu arayüz

## Kullanım

1. `index.html` dosyasını bir web tarayıcısında açın
2. Cihazınızı yatay konuma çevirin
3. Uygulama otomatik olarak drone bağlantısını simüle eder

## Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6+)
- Leaflet.js (Harita)

## Tarayıcı Desteği

- Chrome, Firefox, Safari, Edge (güncel sürümler)
- Mobil cihazlarda en iyi deneyim için yatay mod gereklidir

## Notlar

Bu uygulama şu anda simülasyon modunda çalışmaktadır. Gerçek drone bağlantısı için:
- MAVLink protokol desteği
- WebSocket/WebRTC bağlantısı
- Backend API servisi
gereklidir.
