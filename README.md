# 🚁 Drone Blocks - Mobil Simülasyon

Web tabanlı, mobil uyumlu drone programlama simülasyonu. Blockly ile sürükle-bırak kodlama + Three.js 3D simülasyon.

## 🎮 Nasıl Kullanılır

1. `index.html` dosyasını tarayıcıda açın
2. Telefonu **yatay** çevirin (portrait modda çalışmaz)
3. Sol panelden blokları sürükleyin
4. **▶ ÇALIŞTIR** butonuna basın
5. Drone 3D simülasyonda görevleri gerçekleştirir

## 📱 Özellikler

- ✅ Blockly görsel programlama
- ✅ Three.js 3D grafik
- ✅ Mobil optimizasyonlu
- ✅ Türkçe arayüz
- ✅ Gerçek zamanlı simülasyon
- ✅ Hedef halka sistemi

## 🎯 Drone Komutları

| Blok | Açıklama |
|------|----------|
| 🚀 Kalkış Yap | Drone'u 3m yüksekliğe kaldırır |
| 🛬 İniş Yap | Drone'u yere indirir |
| İleri/Geri X m | Drone'u X metre hareket ettirir |
| Yüksel/Alçal X m | Drone'u dikey hareket ettirir |
| Sola/Sağa Dön | Drone'u 90° döndürür |
| Tekrarla | Komutları döngüye alır |

## 🐛 Hata Giderme

**Eğer "JavaScript generator does not know..." hatası alırsanız:**

1. Tarayıcı konsolunu açın (F12)
2. Sayfayı yenileyin (Ctrl+R / Cmd+R)
3. Console'da hata detaylarını kontrol edin
4. Internet bağlantınızı kontrol edin (CDN'ler için)

**Eğer simülasyon donuyorsa:**
- Sayfayı yenileyin
- "↺ SIFIRLA" butonuna basın
