🚀 KURULUM ADIMLARI:

1. VERİTABANI OLUŞTURMA
   -------------------
   mysql -u root -p
   
   MySQL'de:
   CREATE DATABASE project_management;
   USE project_management;
   SOURCE database.sql;
   
   veya phpMyAdmin'den database.sql dosyasını import edin

2. YAPILANDIRMA
   ------------
   includes/config.php dosyasını düzenleyin:
   
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'project_management');
   define('DB_USER', 'root');
   define('DB_PASS', 'sizin_sifreniz');

3. WEB SUNUCUSUNU BAŞLATIN
   -----------------------
   
   PHP Built-in Server (Geliştirme):
   php -S localhost:8000 -t public/
   
   XAMPP/WAMP:
   Projeyi htdocs klasörüne kopyalayın
   http://localhost/project-management/public
   
   Apache/Nginx:
   Virtual host oluşturun (KURULUM.md'de detaylar)
